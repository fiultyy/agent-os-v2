关键时序点
① MemoryWriterCapability.wrap_run_event_stream 在 native Agent.run stream 耗尽时触发(非 after_run,避免丢中间轮 tool_result)。② _fire_ingest fire-and-forget emit INGEST —— gate 关时 IngestorHook 未注册返 None(no-op);gate 开时 IngestorHook LLM 提炼。③ _fire_kg 直接调 kg.extract_and_ingest(不经 bus),所以 KG 实体抽取即使 side agent 全关仍工作(简化版,非 IngestorAgent 完整 LLM 链)。④ 召回 fire RECALL 修后返 RetrieverHook ranked(带 score);gate 关走 service.recall fallback。

📦 子模块速览

submodules

存储分层(store/sqlitestore/pgstore)

InMemory→SQLite(WAL+迁移列,默认)→Postgres(asyncpg,生产)。同一 store/get/search/block/session 接口。

知识图谱(knowledge_graph + experience_kg)

两套独立 SQLite 图:通用 KG(实体-关系-多跳路径,中英文正则)+ 经验 KG(高复用经验+蝴蝶翼边+技能包)。

召回引擎(_recall)

策略模式:Keyword(子串)/KG(实体反查)/Shared(跨代理权限)/Unified(kw0.4+kg0.6)/Weighted(match×lif)。Semantic NOT-WIRED。

事件总线(event_bus/hooks/default_hook)

9 类生命周期事件按 SYSTEM/OBSERVER 优先级派发。DefaultMemoryHook 核 SYSTEM hook,拥有 working→session→episodic 迁移+压缩。

旁路 LLM Agent(sideline)

4 agent + Hook(Ingestor/Consolidator/Retriever/Curator)+ TaskConsolidation。59695b1 归档,63e2049 env gate 重接。

高级认知场(neural_field + butterfly_wing)

神经状态场(per-concept 电位+基线防漂移)+ 蝴蝶翼双向联想(forward 归纳/backward 锚定)。为 RetrieverAgent 提供 lif 权重。

维护链(db_watcher + state_pruner + forgetting + migrator + compressor)

DBWatcher 轮询触发 → TimeBasedStatePruner(30/90天)→ ActiveForgetting → Migrator(四层)→ Compressor(70%异步/85%同步)。

native capability(harness/capabilities/)

MemoryWriterCapability(写,wrap_run_event_stream)+ MemoryCapability(读,experience_memory/kg_memory tools)。pydantic-ai 2.0,native 主路径。
